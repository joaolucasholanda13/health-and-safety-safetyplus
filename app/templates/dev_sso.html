Como conectar ao Microsoft Entra ID (passo a passo)

Como funciona: o Safety Plus se cadastra na Microsoft como um aplicativo. No login, a pessoa é enviada à Microsoft, que autentica e devolve um código para o endereço de retorno. O servidor troca o código por um token usando o Client secret (o navegador nunca vê o segredo) e lê o e-mail da pessoa. Se existir um usuário ativo com esse e-mail como login, a sessão é criada.

  1. Acesse portal.azure.com → Microsoft Entra ID → Registros de aplicativo → Novo registro.
  2. Nome: Safety Plus. Tipo de conta: somente este diretório.
  3. URI de redirecionamento: tipo Web, com o endereço abaixo (precisa ser idêntico nos dois lados):
    {{ sso.redirect or '' }}
  4. Na Visão geral do aplicativo, copie o ID do aplicativo (cliente) → SSO_CLIENT_ID e o ID do diretório (locatário) → SSO_TENANT_ID.
  5. Certificados e segredos → Novo segredo do cliente. Copie o Valor na hora (depois não aparece mais) → SSO_CLIENT_SECRET. O segredo expira: anote a data para renovar.
  6. Na VPS, edite /opt/safety-plus/.env com o bloco abaixo e rode cd /opt/safety-plus && docker compose up -d web.
  7. Volte a esta tela: o status deve ficar Ativo. Use Testar login SSO e confira em Últimos acessos pelo SSO.
SSO_ENABLED=true
SSO_TENANT_ID=
SSO_CLIENT_ID=
SSO_CLIENT_SECRET=
SSO_ALLOWED_DOMAINS=
SSO_REDIRECT_URI={{ sso.redirect or '' }}

Mantenha o login admin por senha como acesso de emergência. Não envie o Client secret por chat nem salve em git.
